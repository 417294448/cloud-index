# Cloud Product

> Deep analysis and side-by-side comparison of cloud products across AWS, Azure, GCP, and Alibaba Cloud — product mapping, model availability, and version lifecycle intelligence.

**Live site:** [cloudproduct.top](https://cloudproduct.top/)

---

## Overview

Cloud Product is an index hub for cross-cloud product intelligence. It aggregates three specialized analysis modules, each focused on a specific comparison domain. The site is built as a single-page static application hosted on GitHub Pages.

## Modules

| Module | Domain | Repository | Description |
|--------|--------|------------|-------------|
| **Cross-Cloud Product Comparison** | [all.cloudproduct.top](https://all.cloudproduct.top/) | [cloud-compare](https://github.com/417294448/cloud-compare) | Side-by-side product comparison across AWS, Azure, GCP, and Alibaba Cloud. Search any product, find its equivalent, and compare capabilities. |
| **AI Model Availability Matrix** | [llm.cloudproduct.top](https://llm.cloudproduct.top/) | [cloud-model-support](https://github.com/417294448/cloud-model-support) | Foundation model availability on Bedrock, Azure AI Foundry, and Vertex AI. Region coverage, lifecycle status, and inference modes. |
| **Big Data Version Intelligence** | [emr.cloudproduct.top](https://emr.cloudproduct.top/) | [cloud-emr-support](https://github.com/417294448/cloud-emr-support) | Version releases and end-of-support dates for EMR, HDInsight, Dataproc, and Alibaba Cloud EMR. |
| **Database Selection & Analysis** | [db.cloudproduct.top](https://db.cloudproduct.top/) | [db-engines-analysis](https://github.com/417294448/db-engines-analysis) | 400+ database systems ecosystem analysis based on DB-Engines rankings — rankings, models, licenses, and maintenance status with bilingual search & filtering. |
